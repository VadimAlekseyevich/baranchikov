# Полное задание — план и статус

Текущая реализация lab5 ещё НЕ соответствует полному заданию.

## Выполнено
- Исходная слоистая реализация и отдельные тесты классов.
- Определена схема Protocol Buffers в `src/main/proto/exchange.proto`.

## Не выполнено
- Компиляция .proto и интеграция в Maven.
- Отдельный фасад, выполняющий разбор, валидацию и преобразование входных UDP-сообщений.
- Межконтейнерный обмен сообщениями Protocol Buffers.
- Отдельные сервисы business и persistence с согласованным управлением транзакциями.
- Масштабирование каждого компонента, маршрутизация запросов и согласованность данных.
- Нагрузочный генератор, реальные результаты измерений и сравнительная таблица.
- Полный прогон Docker и интеграционных тестов.

## Важное ограничение
Несколько независимых процессов не должны одновременно открывать один и тот же файл H2.
Для масштабирования persistence нужен один владелец БД либо иной механизм координации.

Не выдавать этот промежуточный этап за готовую лабораторную.
