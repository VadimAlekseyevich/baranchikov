# baranchikov

Лабораторные работы по архитектуре программного обеспечения.

В репозитории сохранены отдельные версии работ:

- [lab1](./lab1) — первая лабораторная: валютная биржа, все данные находятся в оперативной памяти;
- [lab2](./lab2) — вторая лабораторная: логическое продолжение первой, состояние биржи сохраняется во встроенной H2-БД и восстанавливается после перезапуска;
- [lab3](./lab3) — третья лабораторная: поверх сохранённой логики и H2 добавлен IP-интерфейс по UDP (вариант 2), включая ответы и асинхронные уведомления отдельными датаграммами;
- [lab4](./lab4) — четвёртая лабораторная: UDP-сервер и тесты запускаются в отдельных Docker-контейнерах, H2 хранится в постоянном Docker volume и переживает перезапуск серверного контейнера.

Хотя каждая следующая работа расширяет предыдущую, папки оставлены отдельно, чтобы каждую лабораторную можно было открыть, запустить и защитить как самостоятельный этап выполнения курса.

Подробные описания находятся в README внутри соответствующих папок.
