# baranchikov

Лабораторные работы по архитектуре программного обеспечения.

## Текущее состояние

Актуальная реализация находится в папке [lab2](./lab2).

`lab2` является логическим продолжением первой лабораторной и включает её функциональность:

- валютная биржа варианта 1;
- Java API;
- limit BUY/SELL orders;
- matching и частичное исполнение;
- уведомления;
- работа клиентов из разных потоков;

а также требования второй лабораторной:

- embedded H2;
- сохранение состояния между перезапусками;
- транзакции;
- восстановление после штатного и нештатного завершения процесса.

Отдельная папка `lab1` удалена, потому что `lab2` является накопительной версией решения.

Подробное описание архитектуры, классов, БД, тестов, алгоритмов и ответы на вопросы для защиты находятся в [lab2/README.md](./lab2/README.md).
