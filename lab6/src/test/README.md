# Где находятся тесты

Открой `src/test/java/org/example/exchange/tests/`. Папки `lab1`, `lab2`, `lab3`, `lab4`, `lab5`, `lab6` соответствуют этапам лабораторных работ.

- `lab1`: вычисления в оперативной памяти, уведомления, параллельная обработка ордеров.
- `lab2`: H2, повторный запуск, аварийное завершение и восстановление, параллельная работа.
- `lab3`: UDP-передача, клиент-серверное взаимодействие, получение уведомлений.
- `lab4`: работа через Docker и проверка состояния после перезапуска (две фазы `seed`/`verify`).
- `lab5`: тестирование независимых слоёв и внутреннего протокола.
- `lab6`: маршрутизация по шардам, отмена ордеров во всех шардах, объединение ответов, интеграционный тест.

Одинаковые старые тесты из нескольких папок лабораторных не дублируются.

Классы в `src/test/java/org/example/exchange/api`, `memory`, `database`, `repository`, `service`, `udp` — поддержка проверок старой реализации. Они не являются рабочим кодом `lab6`. Файл `src/test/java/org/example/exchange/distributed/LayerTestBridge.java` предоставляет тестам доступ к методам слоёв без изменения основной программы.

Локальный запуск: открой `lab6/pom.xml` как Maven-проект и используй `test` в окне Maven. Docker-проверки: `docker compose build`, `docker compose up -d facade`, `docker compose run --rm tests` из папки `lab6`.
